ASRTools v{APP_VERSION} Windows 使用说明
========================================

支持范围
--------
- Windows 10 及以上 x64。
- Windows 7/8、32 位 Windows、Windows ARM64、Linux 和 macOS 不在本版本支持范围。
- 本版本未进行代码签名。首次运行可能出现 Microsoft Defender SmartScreen 提示；若 360、Defender 或其他安全软件查杀，请停止使用并联系销售方重新获取文件，不要关闭安全软件或手动加白。

运行方式
--------
1. 完整解压便携 ZIP，然后运行根目录的 ASRTools.exe。
2. 根目录仅包含启动入口、本文档、_runtime 和 docs。不要单独复制 ASRTools.exe，也不要删除或移动 _runtime。
3. FFmpeg、CPU 运行库和离线模型均已包含在 _runtime 中，无需安装 Python 或另行下载模型。
4. docs 中包含许可证、第三方声明和对应源码获取说明。

基本流程
--------
1. 默认使用本地离线识别。选择 SRT、TXT 或 ASS；离线任务顺序处理，模型在任务间复用。
2. 点击“选择文件”，或把媒体文件、文件夹拖入窗口。
3. 处理全部任务，或勾选后批量处理；可删除正在处理的任务，也可重新处理失败或已完成任务。
4. 结果写入原媒体目录，沿用原文件名并替换扩展名。

离线模式与文件权限
--------------
- 默认离线识别不需要联网；可手动选择 B 接口（需联网）。离线失败不会自动上传音频。
- 界面仅显示阶段状态，不显示实时百分比。
- 原媒体目录必须可写。
- 离线模式的转换文件位于临时目录并自动清理；B 接口的临时 MP3 删除由应用内选项决定。
- 模型位于 _runtime/models，请保持文件名和目录完整；模型校验信息见 docs/MODEL-CHECKSUMS.txt。

完整性校验
----------
交付目录中的 SHA256SUMS.txt 记录最终产物哈希。收到文件后请先核对哈希再运行。
