ASRTools v{APP_VERSION} macOS 使用说明
========================================

支持范围
--------
- macOS 11 及以上（Intel 与 Apple Silicon，按交付包标注架构）。
- Windows、Linux 等不在本包支持范围；请使用对应平台的交付包。
- 本版本未进行签名与公证。首次运行如被 Gatekeeper 拦截，请在“系统设置 > 隐私与安全性”中确认来源后再运行；不要从不明渠道重新下载替换。

运行方式
--------
1. 完整解压便携包，然后在终端运行根目录的 ./ASRTools（将打开 _runtime 内的 ASRTools.app）。
2. 根目录仅包含启动入口、本文档、_runtime 和 docs。不要单独复制 ASRTools.app，也不要删除或移动 _runtime。
3. FFmpeg 与其他运行文件随应用包提供；应用不会调用系统 PATH 中的 FFmpeg。
4. docs 中包含许可证、第三方声明和对应源码获取说明。
5. 随包 FFmpeg 版本为 {FFMPEG_VERSION}，SHA-256 为 {FFMPEG_SHA256}。

基本流程
--------
1. 选择 SRT、TXT 或 ASS；并发数可设为 1–10，并可开启临时 MP3 自动清理。
2. 点击“选择文件”，或把媒体文件、文件夹拖入窗口。
3. 处理全部任务，或勾选后批量处理；可删除正在处理的任务，也可重新处理失败或已完成任务。
4. 结果写入原媒体目录，沿用原文件名并替换扩展名。

联网与文件权限
--------------
- 识别过程需要联网访问 B 站相关服务。
- 原媒体目录必须可写；首次访问受保护目录时按系统提示授权。
- 视频等输入会通过随包 FFmpeg 在原目录生成临时 MP3；是否在任务完成后删除由应用内选项决定。

完整性校验
----------
交付目录中的 SHA256SUMS.txt 记录最终产物哈希。收到文件后请先核对哈希再运行：
shasum -a 256 -c SHA256SUMS.txt
